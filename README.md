# 📖 Sobre o projeto

Este repositório **não possui finalidade comercial ou de produção**.

O objetivo é servir como um ambiente de aprendizado onde desenvolvo projetos, testes e exemplos práticos enquanto estudo o ecossistema do **NestJS**.

Ao longo dos estudos serão explorados diversos conceitos, desde os fundamentos até recursos mais avançados do framework.

## 🚀 Conteúdos estudados

Alguns dos assuntos que serão abordados durante a evolução deste repositório:

- ✅ Estrutura de projetos NestJS
- ✅ Módulos
- ✅ Controllers
- ✅ Providers
- ✅ Services
- ✅ Dependency Injection
- ✅ CRUD
- ✅ DTOs
- ✅ Pipes
- ✅ Validation
- ✅ Prisma ORM
- ⏳ Relacionamentos entre entidades
- ⏳ Autenticação (JWT)
- ⏳ Authorization
- ⏳ Guards
- ⏳ Interceptors
- ⏳ Exception Filters
- ⏳ Upload de arquivos
- ⏳ Testes Unitários
- ⏳ Testes E2E
- ⏳ Deploy

> A lista será atualizada conforme novos módulos forem sendo estudados.

# ⚙️ Como executar

## Instalar as dependências

```bash
npm install
```

## Executar em desenvolvimento

```bash
npm run start:dev
```

## Executar em produção

```bash
npm run start:prod
```

---

# 🧪 Testes

```bash
# Unitários
npm run test

# End-to-End
npm run test:e2e

# Cobertura
npm run test:cov
```

# 🎯 Objetivo

A ideia é entender profundamente como o framework funciona antes de utilizá-lo em projetos maiores, explorando desde conceitos básicos até arquiteturas mais robustas.
